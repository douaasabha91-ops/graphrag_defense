# Results summary

`multiseed_meanstd.csv` and `multiseed_per_run.csv` are the aggregated multi-seed results
reported in the paper (targeted C3 attack, 40-query sessions, 5 seeds).

The full raw run logs (per-query JSONL) and the built knowledge graph are large and are not
committed; they are regenerated by the notebooks. See the repository README for how to
reproduce them.
